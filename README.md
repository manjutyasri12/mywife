# Romantic Valentine's Day Surprise Website

This is a romantic and emotional website created by Manjunath for his wife Kavana as a Valentine's Day surprise. The site features elegant design, smooth animations, floating hearts, a love story, photo gallery, proposal section, and more.

## Features
- Romantic, elegant, and mobile-friendly design
- Soft pink, red, white, and gold color palette
- Floating hearts and animated proposal box
- Optional background music with play/pause button
- Photo gallery with placeholders
- Heartfelt sections: Love Story, Why I Love You, Future Dreams, Proposal
- Interactive proposal buttons

## How to Use
1. Replace the photo placeholders in the gallery with your own images.
2. Optionally, add a romantic music file named `music.mp3` to the `src` folder.
3. Open `index.html` in your browser to view the surprise website.

## Deployment
To deploy or push to GitHub:
1. Initialize a git repository if not already done.
2. Add your remote: `git remote add origin https://github.com/manjutyasri12/mywife.git`
3. Commit your changes: `git add . && git commit -m "Initial romantic website"`
4. Push: `git push -u origin main`
